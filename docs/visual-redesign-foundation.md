# 肘肘猪视觉重设计基础规范

**阶段：** 视觉方向与设计系统建立，不改动现有页面实现。  
**保护基线：** `backup-pre-visual-redesign` 分支与 `pre-visual-redesign` 标签。  
**目标：** 让网站从通用治愈小游戏转为一件有明确作者感的互动小作品：**极简艺术漫画 × 独立小游戏**。

## 1. 核心概念：一张会被肘击的编辑插画

页面不再被理解为“游戏后台 + 一个角色区”，而是一张带有交互的杂志插画：猪猪站在一个安静、留白充足的舞台里，玩家的每次肘击像把一页平静的纸面短暂打皱。

设计配比维持在：

- 70% 编辑插画和海报式构图
- 20% 克制的漫画动作语言
- 10% 冷幽默与荒谬细节

平时的安静和受击时的短促失衡形成对比。动画要像印刷物突然活过来，而不是持续闪烁的游戏特效。

## 2. 角色与场景的关系

### 3D 猪必须保留

现有猪猪资源继续作为唯一有体积感的主角。它保持胖、憨、四肢着地、没有明显脖子、闭眼线条和柔和的 3D 插画质感。不会替换成纯平面图标、写实模型或硬核游戏资产。

### 场景和 UI 转为平面印刷语言

小岛从“可爱游戏地图”转为“舞台底座”：低饱和灰绿块面、少量植物剪影、偏不规则的构图边缘。背景保留天空概念，但从儿童蓝天转为大面积纸张色、低对比色块和少量颗粒感。

由此形成明确对比：**体积化猪猪 + 平面艺术舞台 + 编辑式信息排版**。猪猪会是页面最柔软、最有重量的元素。

## 3. 配色系统

色彩应少、准、可复用。下面的 token 是下一阶段 CSS 重建的唯一基础色，避免重新出现随机浅蓝渐变和大量白卡片。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F1EBDD` | 白天大背景、弹窗底色、留白 |
| `--ink` | `#20231F` | 标题、数字、边界和主要文字 |
| `--moss` | `#52604C` | 岛屿、次级文字、次按钮 |
| `--pig-pink` | `#EFA4A9` | 猪猪相关强调，不替换原猪资源本色 |
| `--mustard` | `#D5A83A` | 主肘击按钮、计数强调、稀有粒子 |
| `--brick` | `#AE5346` | 删除操作、受击爆点、错误状态 |
| `--night-ink` | `#171B28` | 黑夜背景与夜间面板 |
| `--night-paper` | `#D9D6C9` | 黑夜文字与浅色图形 |

规则：一屏同时使用主背景、墨色、灰绿和一个强调色；粉色只服务猪猪与少量受击元素，不能泛滥成 UI 主色。渐变只可用于非常低对比的纸张层次，不能作为按钮和卡片的装饰。

## 4. 字体与信息层级

下一阶段不依赖大量外部字体，先用稳定的系统字体栈建立三层层级：

| 层级 | 建议字体 | 使用位置 | 性格 |
| --- | --- | --- | --- |
| Display | `Georgia`, `Songti SC`, serif | 品牌、猪名、弹窗标题 | 编辑、略带荒谬的温度 |
| HUD | `ui-monospace`, `Cascadia Mono`, monospace | 肘击数字、模式状态、英文小标签 | 像编号与杂志页码 |
| Body | `Microsoft YaHei`, `PingFang SC`, sans-serif | 按钮、列表、表单、说明 | 清楚、克制、易读 |

受击瞬间的“+1”或短字效仅使用 Display 的粗字形，不加入大段拟声词。标题和数字允许大幅变化，正文与表单保持小而清晰。

## 5. 构图与页面分区

### 顶部：编辑页眉，而非工具条

- 品牌放在左上，像刊名；右侧仅保留账号、昼夜、速度三个清楚的状态入口。
- 保存状态缩成小型文字标记，不再像独立的圆角胶囊。
- 顶部按钮使用文字 + 小图形，边框、填充和间距遵守同一节奏。

### 中央：猪猪舞台

- 肘击次数成为舞台旁边的“页码式数字”，而非中心的 dashboard 数字模块。
- 岛屿占据画面中部，但以不规则椭圆、纸片或拼贴构成感出现；不增加真实 3D 场景。
- 猪猪保持最大视觉重量，四周留出足够空白给动作和粒子。
- 猪名改为轻量的编辑注释标签，避免厚重白色胶囊。

### 右侧：猪猪索引，而非后台侧边栏

- “我的猪猪”呈现为收藏索引：紧凑编号、猪名、次数和小缩略图。
- 选中项用短色条、下划线或纸签边缘提示，不用悬浮卡片和厚阴影。
- 创建与删除动作保持清楚，但用编辑符号和文字表现，而不是管理后台图标组。

### 弹窗：杂志夹页

- 使用纸张底色、深墨文字和一条强调色边界。
- 输入框为细线框，获得焦点时用色条或底线强调。
- 注册、登录和删除确认共享同一构图，只由语义颜色区分。

## 6. 组件规范

| 组件 | 默认状态 | 悬停／按下 | 禁用状态 |
| --- | --- | --- | --- |
| 主按钮：肘击 | 芥末底、墨色字、轻微不规则边缘 | 颜色更深、上移 1–2px；按下压回 | 降低对比度、不保留阴影 |
| 次按钮：昼夜／速度／账号 | 纸张或透明底、细墨边 | 背景转为灰绿或墨色 | 文本变灰且不可点 |
| 危险按钮：删除 | 砖红文字或细边 | 砖红填充、纸张色文字 | 低饱和砖色 |
| 猪猪索引行 | 无卡片背景、细分隔线 | 纸色加深、索引条显现 | 不适用 |
| 名字标签 | 纸条式细边、无大阴影 | 下划线或笔尖图标移动 | 不适用 |
| 输入框 | 透明纸色、底线或细边 | 墨色／芥末焦点线 | 低对比且不可输入 |

所有组件只使用 2px 以下的边框与极轻的位移。避免玻璃拟态、厚圆角、漂浮阴影和多层发光。

## 7. 动作与反馈规范

### 肘击

1. 手臂继续遵循“进入 → 肘部接触 → 收回”的真实节奏。
2. 接触瞬间以一个小型不规则爆点、两三条速度线、印刷颗粒和猪的短促压扁传达力量。
3. 眩晕眼仍只在接触后出现，并准确覆盖闭眼位置。
4. 粒子色限制为纸白、芥末、砖红和一点粉色；总量宁少勿乱。
5. 快速模式只压缩时间与提高粒子概率，视觉语言与普通模式一致。

### 悬停和点击

- 悬停统一以颜色加深和极微位移反馈，不使用大阴影膨胀。
- 按下统一表现为向下压 1–3px，并缩短过渡时间。
- 键盘焦点保留清晰外框，保证可访问性。

### 切换猪

- 保留现在的左出右进与缩放深度关系。
- 新设计中让两只猪像跨过同一张纸面的折页，不加额外的旋转、粒子或闪屏。

### 昼夜

- 白天从纸张白和灰绿过渡到夜间墨蓝，而非把所有组件变成发光霓虹。
- 星星仅作稀疏的印刷点；月亮保持稀有、安静和扁平。

## 8. 维护策略与实施边界

本次设计改造将保留现有 `id`、事件绑定、Supabase 配置、表单结构和游戏状态逻辑。视觉工作优先集中在：

1. `dist/style.css`：从当前叠加式覆盖整理为带 token、基础层、组件层、场景层、状态层和响应式层的有序样式。
2. `dist/index.html`：只为语义包装、编辑式标签或可访问性增加必要的轻量结构；不改变现有功能 ID。
3. `dist/assets/`：仅在需要时新增平面舞台、纹理或小图形资源；当前 3D 猪资源保留。
4. `dist/app.js`：仅为增加展示用状态类、可访问标签或反馈容器做最小改动；不重写账号、存档和多猪逻辑。

后续每个视觉步骤先在本地验证登录、注册、切换猪、肘击、昼夜、快速模式和移动端布局，再提交独立 commit。任何失败都可通过备份分支、标签或资源快照恢复。

## 9. 下一阶段页面改造顺序

1. 建立 CSS token 和全局纸张／墨色基底，同时重置过度圆角、阴影和渐变。
2. 改造顶部页眉、信息数字和主肘击按钮，确立字体与交互语言。
3. 重做中央舞台和岛屿平面层，保留猪资源与所有受击定位。
4. 重做猪猪索引、创建／删除入口和弹窗表单。
5. 校准昼夜主题、肘击特效、猪切换转场和移动端布局。
6. 逐项回归验证 Supabase 登录、云同步和 GitHub Pages 部署。
